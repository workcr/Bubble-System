3D Underwater Bubble Simulation

Powered by p5.js + Three.js

About This Simulation

This is a fully 3D translation of the original 2D bubble simulation, combining the strengths of both p5.js and Three.js:

  • p5.js handles the canvas creation, animation loop, physics calculations (using p5.Vector), Perlin noise generation, and UI controls
  • Three.js handles all 3D rendering with PerspectiveCamera, OrbitControls, realistic materials (MeshPhysicalMaterial), and lighting

Features

  • Organic Shape: Bubbles use IcosahedronGeometry with real-time vertex displacement driven by 3D Perlin noise
  • Realistic Materials: MeshPhysicalMaterial with transmission, clearcoat, and environment reflections for soap bubble appearance
  • 3D Physics: Full 3D physics simulation with buoyancy (+Y), drag, drift, and collision detection in a 3D bounding box
  • Contact Deformation: Visual "dents" appear at collision points through localized vertex displacement that fade over time
  • Interactive Camera: Use OrbitControls to rotate (left-drag), pan (right-drag), and zoom (scroll)
  • Background Images: Upload images that appear behind the 3D scene with adjustable opacity and fit mode
  • Export: Record animations as PNG-ZIP or WebM video

Keyboard Shortcuts

  • - / = — Decrease/increase bubble count
  • , / . — Decrease/increase collision iterations
  • g / G — Decrease/increase grid cell size
  • 1 / 2 — Decrease/increase minimum bubble size
  • 3 / 4 — Decrease/increase maximum bubble size
  • R — Start/stop recording

Technical Details

The architecture uses a two-canvas approach to avoid WebGL context conflicts:

  • Background Canvas: p5.js draws a 2D background (white + optional uploaded image)
  • 3D Canvas: Three.js renders the 3D bubbles with transparency, layered on top using CSS positioning

All physics calculations use p5.Vector for 3D positions and velocities, while Three.js handles only the visual rendering of the deformed bubble meshes. The two canvases are stacked using absolute positioning, with the Three.js canvas having a transparent background (alpha: true).
